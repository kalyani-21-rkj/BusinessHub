
# BusinessHub

BusinessHub is a full-stack Business Management System that combines CRM, Sales, Billing, and HR Management into one platform.

## Features

- User Authentication
- Customer Management
- Product Management
- Sales Management
- Invoice Generation
- Employee Management
- Attendance Tracking
- Leave Management
- Payroll Management

## Tech Stack

### Frontend
- React Native
- Expo

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT
- bcryptjs
